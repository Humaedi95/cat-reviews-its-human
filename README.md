# Cat Reviews Its Human

A one-star review, written by a house cat about its human — deadpan, in the
shape of a real review, with a complaint only a cat would file.

> One star. He woke me from a nap to show me a photo of me napping. My bowl was empty. I have reported him to the dog.

## Run it

```sh
python3 main.py
```

This writes the single review line (116 characters, one line) to
`/output/entry.txt`.
